## [0.1.0] - 2026-11-25
### Добавлено
- Модуль `action_log`: запись действий пользователей с уровнями DEBUG, INFO, WARNING, ERROR, CRITICAL и порогом записи
- Фильтры и поиск по уровню, пользователю, действию, тексту и времени, постраничный вывод
- Роли `user`, `auditor`, `admin`: пользователь видит свои записи, аудитор все, администратор может очищать журнал
- Сводка по уровням, частым действиям и пользователям, выгрузка в CSV с защитой от CSV-инъекций
- Автоматическое скрытие паролей и токенов в подробностях записи
- Демо-сайт «Журнал действий» на Flask и Jinja2: заметки, диагностика, журнал, статистика, очистка, защита форм от CSRF
- 47 unit-тестов, покрытие 94 %
- CI на GitHub Actions: сборка, flake8, black, isort, pytest с покрытием
- Пост-мердж проверка (smoke-тест) после слияния в `main`
- Pre-commit хуки, шаблоны Pull Request и Issue

### Исправлено
- Нет, это первый релиз.

### Известные ограничения
- Нет автоматической ротации, очистку запускает администратор
- Журнал не защищён от прямого доступа к файлу базы данных
- #11 (Issue «Текст из поля логина попадает в журнал при неудачном входе»): если пользователь по ошибке введёт пароль в поле логина, он будет записан в журнал
